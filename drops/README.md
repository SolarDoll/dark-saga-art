# drops/ — материалы дропов

Единое место для всего «закулисного» по дропам: идеи, тексты, сырые фото, исходники
обложек, архив прошлых дропов. **Это не подключено к сайту** — живой контент дропа
живёт в [assets/data.js](../assets/data.js) (`DSA.tea` + `DSA.DROP`), а веб-обложки —
в [assets/drop/](../assets/drop/).

## Жизненный цикл

```
workshop  →  upcoming  →  active  →  archive
(идеи)       (назначен    (идёт      (завершён)
             дроп+дата)   live)
```

## Папки

### `workshop/` — рабочие материалы (идеи без даты)
Заготовки персонажей по сериям, ещё не привязанные к конкретному дропу.
- `nightsong/` — серия Nightsong (тема ночи): Eylin, Virel, Lyr, Sylin, Aven, Wynn
- `wildbloom/` — серия Wildbloom (тема цветения): Faelan, Liriel, Fenn, Pell, Senna
- `_templates/` — шаблоны `info.txt` для ти-петов и кукол

Каждый `.md` = один ти-пет: имя, mood, story, atmosphere, personality.
При назначении дропа папка серии переезжает в `upcoming/<дата>-<название>/`.

### `upcoming/` — запланированные дропы
Папка на каждый назначенный дроп: финальный список, сырые фото, исходники обложек,
тизеры. Сейчас: `owl_drop_preview.mp4` — сырой тизер будущего «совиного» дропа.

### `active/` — дроп, который сейчас идёт / финализируется
Материалы дропа в статусе `soon`/`live`. По завершении — переезжает в `archive/`.

### `archive/` — завершённые дропы
- `2026-06-25-tea-spirits/` — первый дроп Tea Spirits (7 духов: Eloran…Zael).
  Сырые фото + `info.txt` по каждому, `_cover-src/` (исходные jpg обложек),
  `README.txt`, `EXAMPLE-iron-harlequin/`.

## Правила текстов (для всех ти-петов)
- Язык — английский.
- НЕ описывать фактуру / цвет / рисунок изделия — только настроение.
- НЕ использовать слова: simply, quite, calm, slow.
- Характеры у всех разные; персонажей между собой не сравнивать.
- НЕ использовать оборот «он не…, он …». Без длинных тире. Простые предложения.
- Имена не повторять с уже существующими (см. `DSA.tea` в data.js).

## Перенос дропа на сайт (на момент запуска)
1. Фото → `assets/works/tea/<name>/01.webp` … (квадрат 1:1).
2. Запись в `DSA.tea` (data.js): `name, mood, avail (1/0), url (Etsy), img, photos[], story, series:"Tea Spirits", atmosphere, personality`.
3. Обложки дропа → `assets/drop/` (см. там же).
4. Конфиг `DSA.DROP` (status/date/cover/featured) — там же в data.js.
